iOS simulator shell captures (task 4.2) — iPhone 17 Pro, iOS 26.2

Captured with the debug-only evidence knobs in AppShell::new (app.rs, same entry
as 4.1's --gallery): `--tab=N` selects a tab, `--dialog` opens a §4.1 confirm,
`--toast` shows the §4.8 toast. simctl cannot tap GPUI elements, hence the knobs.

  xcrun simctl install $UDID build/Build/Products/Debug-iphonesimulator/SnackPilot.app
  xcrun simctl terminate $UDID dev.radaiko.gourmetclient
  xcrun simctl launch   $UDID dev.radaiko.gourmetclient --tab=0   (… 1, 2, 3)
  sleep 6; xcrun simctl io $UDID screenshot tabN.png
  (--toast captured after 1.5 s; the §4.8 machine is 300 ms in + 4 000 ms hold
   + 300 ms out ≈ 4.6 s total, so at 1.5 s the toast is mid-hold, fully visible)
